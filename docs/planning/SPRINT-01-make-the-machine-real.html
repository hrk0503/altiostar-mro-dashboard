Testing excellence — world-class QA lens (research-backed, v1.1)

The best-testers-in-the-world lens + their AI agentic teams

Deep-research inputs folded in (2026 state of the art):
  • Metamorphic testing — the right tool when there is no ground truth (exactly our synthetic case). Instead of asserting a value, assert a relation under input transforms. SHIPPED: tests/test_metamorphic.py — output = max-success, permutation-invariant, adding a worse option never changes the pick.
  • Mutation-guided testing (Meta’s ACH pattern: generate a fault, prove a test catches it; LLM-as-judge for equivalent mutants). SHIPPED: a mutation smoke that flips the optimizer to argmin and asserts the golden expectation fails — proof the harness has teeth.
  • Property-based testing (Hypothesis) — invariants over generated inputs, not hand-picked examples.
  • Golden / regression harness — 20+ known-answer cases every optimizer change must pass.
  • Agentic QA discipline — autonomous test agents are fine, but only with traceability, audit trails, and a human gate (2026 best practice). Pilot on high-churn code first; every AI-generated test is reviewed, never merged blind.
  • Determinism gate — same seed → identical result hash, so any tester (human or agent) can reproduce a claim.
Sources: Meta “Mutation-Guided LLM-based Test Generation” (arXiv 2501.12862) · agentic-QA guidance (Katalon/Autify 2026) · metamorphic-testing survey 2026.
